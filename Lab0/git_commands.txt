1.git clone <ссылка> - скачивает удалённый репозиторий к вам на пк целиком, со всей историей.
2.git status - показывает текущее состояние
3.git add <файл> - добавляет изменения в корзину,готовя их к сохранению.
4. git commit -m "текст" - создаёт сохранение с описанием того, что вы сделали.
5. git push - загружает ваши локальные коммиты на удалённый сервер
6. git pull - скачивает чужие изменения с сервера и сразу объединяет их с вашими.
7. git branch - показывает список всех веток в репозитории
8. git checkout <ветка> - переключает вас на другую ветку.
9. git merge <ветка> - вливает изменения из указанной ветки в текущую.
10. git log - показывает историю коммитов.
