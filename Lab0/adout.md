Что такое Git и для чего он используется?
- Git - это распределённая система контроля версий. Проще говоря, это инструмент, который помогает следить за изменениями в файлах.
В чём разница между централизованными и распределёнными системами контроля версий?
- Централизованные - история только на сервере. Без интернета ничего не сделать, сервер упал - все встало. Распределённые - полная история есть у каждого на пк. Можно работать офлайн, сноано не критичен.
Что такое репозиторий в Git?
- Это папка проекта, за которым Git следит. Там хранятся все файлы и вся история изменений.
